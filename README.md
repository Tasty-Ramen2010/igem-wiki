# igem-wiki

Snapshot of the Denmark-GA iGEM 2026 wiki, copied from https://2026.igem.wiki/denmark-ga/index.html on 2026-10-18.

- `index.html` - home page
- `pages/` - sub-pages (team, description, engineering, wetlab, etc.)
- `static/` - local CSS and JS used by the pages

Remote assets (images, animations) are still loaded from static.igem.wiki and are not mirrored here.
